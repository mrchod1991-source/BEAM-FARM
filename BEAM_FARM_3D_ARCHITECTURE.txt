1. ภาพรวมระบบเกม (SYSTEM OVERVIEW & DESIGN PHILOSOPHY)
================================================================================
Beam Farm 3D เป็นเกมจำลองชีวิตทำฟาร์มแบบ 3 มิติ (3D Diorama Farming Simulation)
ที่ทำงานบนเว็บเบราว์เซอร์ 100% โดยไม่มีการพึ่งพา Backend ภายนอกหรือเซิร์ฟเวอร์ฐานข้อมูล
(Client-Side Self-Contained Application)

หลักการทำงานสำคัญ:
1. Zero External Audio: เสียงเอฟเฟกต์ (SFX) และเสียงเพลงบรรยากาศ (Ambiance) ถูกสังเคราะห์
   ด้วย Web Audio API (Oscillators, Noise Buffers, Biquad Filters) จากโค้ดสดๆ 100%
   ไม่มีการโหลดไฟล์ .mp3 หรือ .wav จึงไม่มีปัญหา 404 หรือเสียงไม่ติด
2. Procedural & Fallback Textures: พื้นผิว ดิน ไม้ หิน หญ้า ถูกวาดขึ้นสดผ่าน HTML5 Canvas API
   และแปลงเป็น THREE.CanvasTexture ทำให้โหลดได้เร็วมากและขนาดเบา
3. Memory Leak Isolation: มีระบบ Cache Stage และคำสั่ง dispose() ทุกระดับ (Geometry,
   Material, Texture) ป้องกันหน่วยความจำสะสมเมื่อเล่นเกมต่อเนื่องเป็นเวลานาน
4. Pointer Event Hardening: ระบบ Raycast ของ Three.js มีตัวกรอง Canvas Event ป้องกัน
   การคลิกปุ่ม UI ทะลุไปโดนแปลงผักหรือฉาก 3D ด้านหลัง

3. เจาะลึกการทำงานของแต่ละส่วน (DETAILED COMPONENT BREAKDOWN)
================================================================================

--------------------------------------------------------------------------------
[3.1] ระบบรากฐานและจุดเริ่มต้น (Entry Point & Lifecycle)
--------------------------------------------------------------------------------
1. `src/main.tsx`:
   - ทำหน้าที่เรียก `createRoot` จาก React 19 เพื่อ Mount เข้ากับ `<div id="root">`
   - รันใน `React.StrictMode` เพื่อความปลอดภัยในการจัดการ Memory และ Hook Lifecycle

2. `src/App.tsx`:
   - โหลดข้อมูลบันทึกเริ่มต้นและ Render หน้าจอ `LoadingScreen` ในช่วงแรก
   - เมื่อโหลด Assets ครบ 100% จะเปิดเข้าสู่ `FarmWorld`

--------------------------------------------------------------------------------
[3.2] แกนประมวลผล 3D (3D Engine & Graphics Core)
--------------------------------------------------------------------------------
1. `src/components/3d/FarmScene.tsx`:
   - ควบคุม Three.js Scene, Camera, WebGLRenderer, และ Animation Loop (requestAnimationFrame)
   - จัดการระบบ Raycaster เพื่อดักจับการคลิก (Pick) วัตถุต่างๆ ในฉาก 3 มิติ:
     - คลิกแปลงผัก -> เรียก `onPlotClick` เพื่อขุดดิน/ปลูก/รดน้ำ/เก็บเกี่ยว
     - คลิกต้นไม้ -> เขย่าต้นไม้ / เก็บผลไม้ / โค่นต้นไม้
     - คลิกสัตว์เลี้ยง -> เล่นเสียงสัตว์ / ลูบตัว / แสดงหัวใจลอย
     - คลิกซุ้มประตูแดนรกร้าง -> เปิดหน้าต่างขยายที่ดิน Lv.10
     - คลิกสิ่งปลูกสร้าง/หิน -> เลือกเพื่อย้ายตำแหน่งหรือหมุน
   - จัดการระบบ Ghost Preview ขณะผู้เล่นเลือกสิ่งของมาวาง

2. `src/components/3d/FarmCameraControls.ts`:
   - ระบบควบคุมมุมมองกล้อง 360 องศา (Orbit Rotation, Pan, Pinch-to-Zoom, First-Person View)
   - **Canvas Isolation Guard (แก้บัคคลิกทะลุ)**:
     - ดักจับ `pointerdown` บน `<canvas>` เท่านั้น หากผู้เล่นคลิกบนปุ่ม UI กล้องจะไม่รับอินพุต
     - `handlePointerUp` จะทำงานเฉพาะเมื่อการคลิกเริ่มต้นจาก Canvas และไม่เกิดการลาก (Drag)
     - ป้องกันการที่ผู้เล่นคลิกปุ่ม "หมุน" หรือ "เลื่อน" ในโหมดวางของแล้วสิ่งของถูกวางลงทันที

3. `src/core/Lighting.ts`:
   - สร้างแสงแดด DirectionalLight (Sun Light) พิกัด (38, 55, 30) ส่องเงา PCFSoftShadowMap
   - สร้างแสงท้องฟ้า HemisphereLight จำลองแสงสะท้อนจากพื้นหญ้าและท้องฟ้า
   - ปรับการแสดงผลสีแบบ ACESFilmicToneMapping และ sRGB Color Space ให้ภาพดูนุ่มนวล

4. `src/components/3d/FarmTerrain.ts` & `FarmTerrainMap2.ts`:
   - `FarmTerrain.ts`: แผ่นดินเกาะฟาร์มหลักขนาด 104 x 78 หน่วย มีการวางจานน้ำสระน้ำที่พิกัด (-40, -28) รัศมี 5.2
   - `FarmTerrainMap2.ts`: ส่วนต่อขยายทุ่งทองคำฝั่งซ้าย (X: -62, Z: 0) มีซุ้มประตูไม้และป้ายล็อก Lv.10

5. `src/components/3d/FarmGrass.ts`:
   - สร้างต้นหญ้า 3D จำนวน 8,500 ต้นด้วย `THREE.InstancedMesh` (Single Draw Call)
   - มี Custom Vertex Shader จำลองการพริ้วไหวตามแรงลม (Wind Sway Animation)
   - โหลด `farm-map.jpg` มาทำเป็น Alpha Mask เพื่อไม่ให้ต้นหญ้าไปงอกบนถนน แม่น้ำ หรือสระน้ำ

--------------------------------------------------------------------------------
[3.3] ระบบการเพาะปลูกและพืชผล 3D (Crops & Agriculture Pipeline)
--------------------------------------------------------------------------------
1. `src/components/3d/FarmCrops.ts`:
   - โมเดล 3 มิติของพืช 6 ชนิด: ข้าวสาลี, ข้าวโพด, แครอท, มะเขือเทศ, ฟักทอง, สตรอว์เบอร์รี
   - แบ่งระยะการเจริญเติบโตเป็น 4 ระยะ: ดินว่าง (EMPTY), พรวนดิน (PLOWED), เพิ่งงอก (PLANTED), กำลังโต (GROWING), สุกพร้อมเก็บ (READY)
   - **Cache Stage Keys**: จดจำสถานะของแปลงผัก ไม่สร้าง 3D Mesh ซ้ำทุกๆ วินาที ช่วยลดภาระ GPU
   - **Dispose Memory**: ทำการ dispose Geometry และ Material เก่าทิ้งทุกครั้งที่เปลี่ยนสถานะ ป้องกันแรมรั่ว

2. `src/hooks/useFarmPlots.ts`:
   - จัดการข้อมูลแปลงผักทั้งหมด 48 แปลง (Zone 1 - 5)
   - **Growth Timer Loop**: รันลูปนับเวลาการเติบโตตามค่าสถิติของพืชแต่ละชนิด
   - **Overnight Sleep Logic (แก้บัคนอนปั๊มผักฟรี)**:
     - เมื่อผู้เล่นนอนหลับข้ามวัน แปลงที่ได้รับการรดน้ำ (`isWatered: true`) จะเติบโตขึ้นทันที +35%
     - ในเช้าวันใหม่ น้ำจะแห้งลง (`isWatered: false`) ผู้เล่นต้องรดน้ำใหม่ในแต่ละวัน
     - แปลงที่ไม่ได้รดน้ำจะไม่โตฟรีข้ามคืน

--------------------------------------------------------------------------------
[3.4] ระบบต้นไม้และป่าไม้ (Forestry & Orchard Pipeline)

[3.8] ระบบเก็บเกี่ยวผลผลิตอัจฉริยะ (Smart Harvest Mode Subsystem)
--------------------------------------------------------------------------------
1. `src/hooks/useHarvestMode.ts`:
   - State Machine: จัดการ 4 สถานะ (IDLE -> SELECTING -> EXECUTING -> COOLDOWN)
   - Idempotency & Concurrency Guard: ป้องกันการกดซ้ำซ้อนขณะประมวลผล
   - Atomic Stamina: ตรวจสอบและหักพลังกายรวดเดียว หากพลังกายไม่พอจะปฏิเสธทั้งชุด
   - Continuous Mode: หลังพ้นคูลดาวน์จะวนกลับเข้าโหมดเลือกอัตโนมัติอย่างราบรื่น
2. `src/hooks/useHarvestQueue.ts`:
   - Sequential Worker: คิวเก็บเกี่ยวทีละรายการแบบกำหนดช่วงเวลา (Tick Interval)
   - Re-validation: ตรวจสอบความสุกของเป้าหมายก่อนเก็บจริง ป้องกัน Race Conditions

4. วงจรการทำงานของเกมในแต่ละเฟรม (FRAME-BY-FRAME EXECUTION CYCLE)
================================================================================
1. Input Layer (Pointer/Touch/Keyboard)
   - ดักจับการแตะหน้าจอหรือคลิกเมาส์
   - กรองว่าเกิดบน Canvas 3D หรือ UI 2D
   
2. Camera & Control Update
   - `FarmCameraControls` คำนวณตำแหน่งกล้องแบบ Lerp Smooth ตามตัวละครหรือจุดเป้าหมาย

3. Scene Raycasting & Pick Target
   - ตรวจสอบว่าพิกัดเคอร์เซอร์ตรงกับแปลงผัก ต้นไม้ สัตว์ หรือสิ่งปลูกสร้างใด

4. Game Logic Update (Tick 1s / Differential Loop)
   - `useFarmPlots` และ `useFarmTrees` ตรวจสอบความคืบหน้าการเติบโต
   - `FarmAnimals` ขยับตำแหน่งสัตว์ตาม AI สุ่มทิศทาง

5. Render Pipeline
   - WebGLRenderer คำนวณ ShadowMap, ToneMapping, Vertex Shaders ของต้นหญ้า
   - วาดภาพเฟรม 3D ออกสู่หน้าจอด้วยความเร็ว 60 FPS

5. สรุปจุดเด่นทางวิศวกรรม (ENGINEERING HIGHLIGHTS)
================================================================================
- ปราศจากบัคคลิกทะลุ UI 100% ด้วย Canvas Event Isolation Architecture
- ปราศจากปัญหาหน่วยความจำรั่วไหลด้วย Three.js Dispose Pattern ทุกเลเยอร์
- ปราศจากการปั๊มเงิน/XP/ผลผลิต ด้วยระบบ Overnight Moisture Verification และ Cooldown Timers
- ทำงานได้ไหลลื่นทั้งบนคอมพิวเตอร์และสมาร์ตโฟนด้วยการ Optimize Draw Calls ผ่าน InstancedMesh
