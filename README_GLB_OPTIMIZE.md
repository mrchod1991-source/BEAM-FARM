# วิธีใช้ชุดลดขนาด GLB + วางฉากตามงบ

## 1) วางไฟล์ทับโปรเจกต์
แตก zip นี้ทับโฟลเดอร์โปรเจกต์ (โครงสร้างโฟลเดอร์ตรงกัน) แล้วรัน `npm install`

## 2) ลดขนาด GLB (รันบนเครื่องคุณ)
```bash
npm run optimize:glb:dry     # ดูรายงานก่อน ไม่แก้ไฟล์
npm run optimize:glb         # ทำจริง สำรองต้นฉบับที่ public-original-glb/
```
- ย่อ texture ตามงบ → WebP, รวม/ล้างข้อมูลซ้ำ, ลด tris (เฉพาะโมเดลที่ไม่มีโครงกระดูก), บีบ geometry ด้วย Meshopt
- โค้ดเกมถูกแก้ให้ถอดรหัส Meshopt ได้แล้ว (`createGLTFLoader` ใน `src/utils/glbLoaderSetup.ts`)
- ไฟล์ที่ยังเกินงบจะถูกแจ้งท้ายรายงาน (`glb-optimize-report.json`) ต้องลดมือใน Blender
- ถ้าไม่อยากให้บีบ geometry: `node scripts/optimize-glb.mjs --no-meshopt`

## 3) งบขนาด (แก้ได้ที่ `src/config/modelBudgets.json`)
| ประเภท | ไฟล์ | tris | texture |
|---|---|---|---|
| พืช/หญ้า | ≤ 500 KB | 3,000 | 512 |
| ต้นไม้ | ≤ 1 MB | 6,000 | 1024 |
| หิน/ของตกแต่งเล็ก | ≤ 500 KB | 3,000 | 512 |
| สิ่งปลูกสร้าง | ≤ 3 MB | 20,000 | 2048 |
| สัตว์/ตัวละคร | ≤ 3 MB | 10,000 | 1024 |
| รวมโหลดครั้งแรก | ≤ 40 MB | | |
| tris ฉากตกแต่งรวม | มือถือ 80,000 / เดสก์ท็อป 200,000 | | |

เกินงบไม่เกิน 2 เท่า = เตือนใน console, เกิน 2 เท่า = ไม่วางเป็นฉากตกแต่ง

## 4) ฉากตกแต่ง (`src/components/3d/FarmScenery.ts`)
- วางกังหันลม หอส่งน้ำ บ้านไม้ เสาไฟ ต้นสน มะนาว มะพร้าว หญ้า หินริมน้ำ นอกขอบแผนที่ฝั่งขวา/เหนือ/ใต้ (เลี่ยง Map 2 ฝั่งซ้าย)
- แก้รายการ/จำนวน/ตำแหน่งที่ `DEFAULT_SCENERY` และ `DEFAULT_ZONES`
- ใช้ InstancedMesh ลด draw call, ไม่มี collision, ไม่แตะระบบต้นไม้/บ้านของเกมเดิม
- ถ้าไฟล์ใดไม่มี/เสีย/เกินงบ จะข้ามเงียบ ๆ พร้อมรายงานใน console `[Scenery]`
