    - แถบเมนูเลื่อนแนวนอนลื่นไหล ข้อความไม่ตกบรรทัดซ้อนกัน ปุ่มสัมผัสขนาดเหมาะสมกับนิ้วมือ

    - รองรับปุ่ม Esc บนคีย์บอร์ด และปุ่มย้อนกลับของ Android (Hardware Back / popstate) เพื่อปิดหน้าต่างหรือยกเลิกโหมดวางของโดยไม่หลุดออกจากตัวเกม
[✔] 12. รองรับ Web, PWA และ Android APK พร้อมชุดไอคอนมือถือครบทุกขนาด:

[✔] 13. รองรับ 2 ภาษา (ไทย / English) แยกออกจาก Gameplay Logic:
    - เพิ่มโมดูลภาษา src/i18n/translations.ts และ src/i18n/LanguageContext.tsx
    - กดสลับปุ่ม TH / EN ได้ทันทีจากแถบด้านบนหรือในหน้าตั้งค่า แปลครบทั้ง UI, เครื่องมือ, พืชผัก 6 ชนิด, ต้นไม้ 6 ชนิด, สิ่งปลูกสร้าง 21 แบบ, สัตว์เลี้ยง, หินแร่, โซนขยายที่ดิน 5 โซน, สูตรอาหาร 6 เมนู และข้อความแจ้งเตือนการวางวัตถุ
[✔] 14. รองรับการเล่นออฟไลน์ในส่วนที่เตรียมข้อมูลไว้แล้ว (Offline-Ready):
    - Service Worker (Workbox) พรีแคชไฟล์ระบบหลัก (HTML/JS/CSS/ไอคอน/ภาพ) และแคชโมเดล 3D (.glb) แบบ CacheFirst (เฉพาะ HTTP 200)
    - เพิ่มระบบ "เตรียมข้อมูลออฟไลน์" (src/utils/offlineAssets.ts) ให้กดดาวน์โหลดโมเดล .glb ทั้ง 19 ไฟล์เก็บลงเครื่องล่วงหน้า พร้อมแถบความคืบหน้า ตัวนับไฟล์แคช ขนาดพื้นที่จริง และปุ่มล้างแคช
    - เพิ่มตัวตรวจสถานะเครือข่ายแบบเรียลไทม์ (useOnlineStatus.ts) แสดงป้ายสถานะออฟไลน์และสลับใช้โมเดล Procedural สำรองอัตโนมัติหากไฟล์ยังไม่ถูกแคช
[✔] 15. ระบบตรวจสอบ GLB ล่วงหน้า, จัดการ Memory/GPU, Mobile Performance และกัน Event ซ้ำ:
    - เพิ่ม src/utils/glbValidator.ts (inspectGLBBuffer, loadValidatedGLTF, optimizeGLTFSceneForDevice, disposeHierarchySafely) ตรวจสอบไบนารี .glb ทุกไฟล์ก่อนส่งเข้า Three.js ป้องกันไฟล์ 0 ไบต์หรือหน้า HTML 404 ทำให้เอนจินแครช
    - ปรับประสิทธิภาพมือถือใน FarmScene.tsx (จำกัด DPR <= 1.35, Shadow Map 512, หญ้า 2,400 ใบ, คุมงบประมาณเงาตามจำนวนสามเหลี่ยม, รองรับ ResizeObserver และ WebGL Context Lost/Restored)
    - ป้องกันการล้าง Geometry แม่แบบของ GLB ที่แชร์ผ่าน SkeletonUtils.clone (isSharedGlbGeometry) ขณะคืนหน่วยความจำของ Procedural Geometry ที่ถูกลบ
    - ป้องกัน Event ซ้ำบนมือถือใน FarmCameraControls.ts (บล็อก Synthetic Mouse Event 500ms หลัง Touch + Debounce การคลิกเลือกวัตถุ 80ms)
[✔] 16. บันทึกผลการทดสอบจริงครบทุก Milestone:

===============================================================
การไหลของข้อมูลและหลักสถาปัตยกรรมสำคัญ
===============================================================
1. main.tsx -> App.tsx (LanguageProvider) -> FarmWorld.tsx
2. แยกหน้าที่อย่างเป็นระบบ:
   - UI (components/ui/* + i18n/*) แยกออกจาก Gameplay Logic (hooks/*)
   - AI & Entity State (types/game.ts + FarmAnimals.ts state) แยกออกจาก Visual Model (animals/* + FarmHouses.ts)
   - การโหลดโมเดล 3D ทั้งหมดผ่านตัวกรอง glbValidator.ts พร้อมระบบสำรอง Procedural เมื่อออฟไลน์
   - รองรับการทำงานข้ามแพลตฟอร์มครบทั้ง Web, PWA (Service Worker Offline Cache) และ Android APK
