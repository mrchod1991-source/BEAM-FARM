⚠️ Troubleshooting

        

          

            ไม่พบ mesh 'Object_7'
            
ตรวจชื่อ object ใน Outliner — ถ้าเปลี่ยนชื่อไปแล้ว ให้แก้ TARGET_OBJECT ให้ตรง

          

          

            ไม่พบ vertex group 'Body_00'
            
เลือก Object_7 → tab Object Data Properties (ไอคอนสีเขียว) → ดูในส่วน Vertex Groups

          

          

            UV ไม่พอดี / โลโก้เบี้ยว
            
เปิด SCALE_TO_BOUNDS = True ในโหมด UV หรือใช้ USE_BOX_PROJECT = True ในโหมด Texture

          

          

            โลโก้โปร่งใสไม่ขึ้น
            
ตรวจ PNG มี alpha channel + blend_method = 'HASHED' (Blender 4.x)

          

          

            Blender 4.x: input 'Clearcoat' ไม่มี
            
Blender 4.x ใช้ 'Coat Weight' แทน — สคริปต์เช็คให้อัตโนมัติแล้ว

          

          

            โหลดรูปไม่เจอ (FileNotFoundError)
            
Path //textures/xxx.png เป็น relative กับ .blend → ต้อง save .blend ก่อน หรือใช้ absolute path
